Healthcare Analysis and Insights

Project Overview

This project focuses on analysing healthcare data using Microsoft Excel. The analysis was performed to identify patterns and relationships between patient health conditions, healthcare charges, hospital information, and other healthcare factors.

Data Analysis Performed

The following analyses were completed:

1. Cancer history distribution among smokers and non-smokers.
2. Major surgeries and average HbA1C based on transplant history.
3. Healthcare charges based on weight status and diabetes status.
4. Average healthcare charges by hospital tier and state.
5. Relationship between age and BMI.
6. Relationship between age and HbA1C.
7. Relationship between age and healthcare charges.

Dashboard

An interactive dashboard was created to consolidate the key insights from the analysis.

The dashboard includes:

- Doughnut charts
- Column/Bar charts
- Scatter charts
- Weight Status slicer
- Diabetes Status slicer

The slicers allow users to filter the dashboard and compare health outcomes and healthcare charges based on weight status and diabetes condition.

Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas
- Data cleaning and transformation

Conclusion

The analysis provides a clear overview of healthcare patterns in the dataset and helps understand how different patient and hospital factors are associated with healthcare outcomes and charges.
